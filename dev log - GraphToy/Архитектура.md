# Архитектура
Используем а-ля ECS, никакого наследования блят, просто компонентами срем и все. Проверка ноды на соответствие шаблону - через class_name: 

```gdscript
extends Node2D
class_name MyObject
```

```gdscript
extends Node2D
class_name MyComponent
func do_stuff() -> void:
```

и ключевое слово is
```gdscript
if myNode is MyObject:
	myNode.MyComponent.do_stuff()
```

Компоненты назначаем через дерево и открываем для инспектора, чтобы новый класс хорошо с ними взаимодействовал
```gdscript
# У этого объекта есть дочерняя нода MyComponent
@export var myComponent: MyComponent
# в инспекторе указываем нужную ноду и готово!
func _ready() -> void:
	myComponent.do_stuff()
```
